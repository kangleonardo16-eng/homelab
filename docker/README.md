# Docker

---

## Objective 

Deploy Docker on Ubuntu Server to run applications in isolated containers

---

## Why I Chose Docker

- Industry standard container platform
- Makes application deployment consistent and repeatable
- Widely used in cloud and DevOps environment

---

## What I Learned

- The difference between virtual machines and containers
- Containers share the host operating system kernel instead of running a full guest operating system
- How Docker images are used to create containers
- How Docker compose can define and deploy multiple services from a single configuration file
- Why containers provide application level isolation while virtual machines provide operating system level isolation
- How docker fits into a layered infrastructure design

---

## Outcome

Successfully deployed Docker on Ubuntu Server and used it to host Portainer, Uptime Kuma, and Pi-hole
