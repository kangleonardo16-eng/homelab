# Portainer

---

## Objective

Deploy Portainer to simplify Docker container management through a web based interface.

---

## Why I Chose Portainer

I chose Portainer because it provides a graphical interface for managing Docker containers, images, networks, and volumes without relying solely on the command line.

---

## What I Learned 

- How Portainer connects to and manages a Docker environment
- How Docker containers, images, volumes, and networks can be viewed and managed from a central dashboard
- How Portainer simplifies container administration by providing a web based interface for docker
