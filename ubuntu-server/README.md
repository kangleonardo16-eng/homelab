# Ubuntu Server

## Objective 

Deploy an Ubuntu Server Virtual machine on Proxmox to host services and provide a Linux enviornment for learning system administration.

---

## Why I Chose Ubuntu Server

I chose Ubuntu Server because it's widely used in enterprise and cloud enviornments, has extensive documentation, and works well as a platform for self hosted services.

---

## What I learned 

- The difference between a desktop operating system and a server operating system.
- How to remotely manage a server using SSH.
- Basic Linux navigation and file management.
- How virtual machines can provide isolated enviornments for services.
- I learned that modern IT infrastructure is built in layers. Each layer has a specific responsibility and relies on abstraction to interact with the layer below it. This allows services to be moved, replaced, or rebuilt without affecting the entire system.

---

## Outcome 

Successfully deployed an Ubuntu Server virtual machine on Proxmox and used it as the foundation for Docker, Portainer, Uptime Kuma, and Pi-hole.
